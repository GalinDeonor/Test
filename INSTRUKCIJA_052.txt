ИНСТРУКЦИЯ 0.52 — «Пьяный Петух» (FUST Survival)
==================================================

ЧТО НОВОГО ПО СРАВНЕНИЮ С 0.51
1. Авто-стрельба: движок выстрела заменён на движок VOMAGLA — того самого
   скрипта, который у тебя на телефоне не крашился НИ РАЗУ. Порядок:
   mouse1click → VirtualInputManager (отжатие через task.defer — клик
   «живёт» до конца кадра) → Tool:Activate() как финальный фолбэк.
   Ветвление по флагам клавиатуры/тача убрано: экзекуторы врут во флагах,
   теперь у всех устройств один путь — как в VOMAGLA.
2. Внутри ВСЕ фиксы 0.51 (E-15: убит стартовый скан Workspace, из-за
   которого 0.50 вешала Delta чёрным экраном; E-16: CanvasGroup → Frame).
   Если 0.51 ещё не заливал — заливай сразу 0.52, она включает всё.

ЧТО ЗАЛИТЬ НА GITHUB ОДНИМ КОММИТОМ (корень GalinDeonor/Test)
1. Fust1..Fust6            — ЗАМЕНИТЬ (новые части 0.52)
2. manifest.json           — ЗАМЕНИТЬ
3. FUST_loader_delta_052.txt — ДОБАВИТЬ
4. BUGS.md                 — ЗАМЕНИТЬ (добавлена E-17)
5. FUST_xeno_052.lua       — ДОБАВИТЬ (полный скрипт для Xeno/ПК)
УДАЛИТЬ: все старые лоадеры (051, 050, 049, 048...), а также одиночный
файл Fust — в репе лежит старьё, только путает.

ЗАПУСК НА DELTA (телефон)
1. Delta → вкладка со старым лоадером → стереть текст → вставить текст
   FUST_loader_delta_052.txt → EXECUTE.
2. В консоли должно появиться:
   [ПП 0.52] Лоадер запущен, качаю 6 частей с GitHub...
   [ПП 0.52] Часть 1: ... байт (и так все 6)
   [FUST] 1/4: запуск скрипта... → 2/4 → 3/4 → 4/4
3. Чёрный сплэш «ПЬЯНЫЙ ПЕТУХ 0.52» исчезает сам через ~3 секунды.
   Если чёрный экран висит дольше 10 секунд — скинь скрин консоли Delta.

ПРОВЕРКА (по пунктам, в этом порядке)
1. Сплэш ушёл через ~3 сек, игра живая, FPS как до запуска.
2. Меню открывается кнопкой-петухом.
3. Авто-стрельба: Аимбот → тумблер «Авто-стрельба (когда есть цель)» → ВКЛ.
   Наведи прицел на цель (или включи аимбот) — оружие стреляет само,
   игра НЕ фризит. WallCheck: цель за стеной — не стреляет.
4. X-Ray: вкладка ESP → «Мир и освещение» → тумблер — включается с паузой
   1-3 сек (чанковый скан), БЕЗ фриза (фикс 0.51 на месте).
5. Фрикам: страница «Фрикам» → тумблер — панель CAM, персонаж на якоре.

XENO (ПК)
Запускай FUST_xeno_052.lua целиком. Отличие от 0.51 только в движке
авто-стрельбы (E-17), фичи те же.

ПОСЛЕ ПРОВЕРКИ
Скажи: 1) запустилась ли 0.52 на Delta, 2) стреляет ли авто-стрельба,
3) живы ли X-Ray и фрикам. Отмечу статусы в BUGS.md.
