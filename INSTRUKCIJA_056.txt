ИНСТРУКЦИЯ 0.56 — «Пьяный Петух» (FUST Survival)
==================================================

ЧТО НОВОГО ПО СРАВНЕНИЮ С 0.55 (всё по твоим приказам)
1. АВТО-СТРЕЛЬБА: движок VOMAGLA (0.52) НЕ СТРЕЛЯЛ — вернул СТАРЫЙ движок,
   тот самый, что с линии 0.39 работал на Xeno: ПК — mouse1click /
   VirtualInputManager, телефон — Tool:Activate(). Настройки те же
   (задержка, «только при цели», «не стрелять через стены»).
2. РАЗБОР БАНА «WALKSPEED 1000, IQ 0» (10 лет, был на 0.54):
   - в 0.55 уже удалена кнопка TELEPORT TO CAM (мгновенный телепорт
     ПЕРСОНАЖА к камере — за такое и банят);
   - в 0.56 удалена ЯКОРЬ-ЗАМОРОЗКА персонажа. Теперь фрикам НЕ ПИШЕТ НИ
     ОДНОГО свойства персонажа: ни Anchored, ни CFrame, ни скорости.
     Управление просто отключается — персонаж стоит как обычный игрок,
     сервер видит обычного стоящего игрока. Летает ТОЛЬКО камера.
   ВАЖНО: персонаж теперь можно убить, пока ты летаешь камерой (раньше
   якорь давал «вечную стоянку») — это плата за безопасность.
3. FOV-КРУГ «КРУТОЙ» (по твоему скрипту): Аимбот -> «FOV круг».
   - вращающееся градиентное кольцо (как в твоём образце);
   - КРАСНО-ЧЁРНОЕ, когда аимбот никого не видит;
   - СПЛОШНОЕ ЗЕЛЁНОЕ, когда цель захвачена;
   - ДВА ЦВЕТА настраиваются (два квадратика-цвета рядом с тумблером);
   - толщина линии (1-12, по умолчанию 5) и скорость вращения (0-8);
   - размер круга = ползунок FOV;
   - работает даже в экзекуторах без Drawing API (это обычный GUI).

ЗАПУСК НА DELTA (телефон)
1. Delta -> вкладка со старым лоадером -> стереть текст -> вставить текст
   FUST_loader_delta_056.txt -> EXECUTE.
2. В консоли должно появиться:
   [ПП 0.56] Лоадер запущен, качаю 6 частей с GitHub...
   [ПП 0.56] Часть 1: ... байт (и так все 6)
   [FUST] 1/4: запуск скрипта... -> 2/4 -> 3/4 -> 4/4
3. Сплэш «ПЬЯНЫЙ ПЕТУХ 0.56» исчезает сам через ~3 секунды.
   ПОМНИ ПРО E-18: если умирает молча — сначала ЧИСТИ воркспейс экзекутора.

ПРОВЕРКА (по пунктам, в этом порядке)
1. Сплэш ушёл через ~3 сек, игра живая.
2. АВТО-СТРЕЛЬБА: Аимбот -> «Авто-стрельба» ВКЛ (+ аимбот ВКЛ), наведи на
   цель — оружие стреляет само. Проверь и на Xeno, и на Delta.
3. ФРИКАМ: страница «Фрикам» или кнопка CAM -> FLY. Полети — ПОТОМ
   выключи и посмотри на своего персонажа со стороны (со второго
   аккаунта/друга): он должен СТОЯТЬ как обычный игрок, без аномалий.
   Никаких телепортов персонажа больше нет вообще.
4. FOV-КРУГ: Аимбот -> «FOV круг» ВКЛ -> в центре вращающееся кольцо.
   Без цели — красно-чёрное. Наведи аимбот на цель — вспыхнет ЗЕЛЁНЫМ.
   Покрути цвета (квадратики у тумблера), толщину, скорость вращения.
5. Конфиг: сохрани конфиг, перезайди, загрузи — цвета FOV-круга должны
   вернуться.
6. Всё из 0.55 на месте: меню фрикама (CAM -> меню), логи, Журнал
   (Логи -> Журнал чита), конфиги с подтверждением, X-Ray.

XENO (ПК)
Запускай FUST_xeno_056.lua целиком. На Xeno сначала проверяем стрельбу —
старый движок на нём и работал.
