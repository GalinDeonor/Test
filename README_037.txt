ПЬЯНЫЙ ПЕТУХ 0.37 — FUST Survival
=====================================

ЧТО НОВОГО (все правки — по твоим багам с Xeno и телефона):

1. ФРИКАМ НА XENO: КАМЕРА ТЕПЕРЬ ВЕРТИТСЯ.
   Обзор: ЗАЖМИ ПКМ и веди мышью.
   Причина бага: старый код брал поворот через GetMouseDelta, а он в
   Roblox работает только с заблокированной мышью и без неё всегда
   даёт (0,0) — поэтому камера «стояла» на месте.

2. ТЕЛЕФОН (Delta): ПЕРСОНАЖ БОЛЬШЕ НЕ ХОДИТ ВО ВРЕМЯ ФРИКАМА.
   Тело заякоривается на месте (после выключения фрикама всё
   возвращается как было). Управление с телефона:
   - ЛЕВЫЙ ДЖОЙСТИК — полёт камеры (в сторону джойстика)
   - палец по ПРАВОЙ половине экрана — обзор (джойстик камеру не крутит)
   - кнопка ПРЫЖКА — набор высоты, пока держишь
   - тумблер «Авто-полёт вперёд» и слайдер скорости — в меню, как было

3. НОВЫЕ КЛАВИШИ (Xeno) — старая F конфликтовала с игрой, [ и ] не на
   всех раскладках:
   K — фрикам вкл/выкл
   Z — скорость полёта МЕНЬШЕ (шаг 5, от 5 до 300)
   X — скорость полёта БОЛЬШЕ
   WASD — лететь, Space — вверх, Ctrl — вниз, Shift — ускорение x2.5
   P — авто-предикт злого аима вкл/выкл (как было)
   RightControl — показать/скрыть меню (или тап по кнопке-петуху)

4. МЕНЮ БОЛЬШЕ НЕ ОБРЫВАЕТСЯ МОЛЧА («нету функций и вкладок»):
   - вкладки собираются блоками: если один блок падает — остальные
     всё равно собираются;
   - если что-то не собралось, внизу ГЛАВНОЙ вкладки появляется
     красная секция «ОШИБКИ СБОРКИ (скрин — в чат)» с текстом ошибки;
   - если упал ВЕСЬ запуск — на экране появляется красное окно
     «ПЬЯНЫЙ ПЕТУХ 0.37 — ОШИБКА ЗАПУСКА» с текстом ошибки.
   В ОБОИХ СЛУЧАЯХ: ОТПРАВЬ СКРИН этой плашки/окна в чат — я починю
   сразу по конкретному месту, без угадываний. В консоли экзекутора
   при этом будут строки [FUST][UI] ОШИБКА БЛОКА '...' — тоже годится.

5. ЛАГИ: проверка видимости злого аима кэшируется на 0.15с — раньше
   было 2 raycast'а на каждого игрока КАЖДЫЙ кадр. Меньше нагрузки,
   выше FPS при включённом аиме.

КАК ОБНОВИТЬ (XENO, ПК):
   1. Открой Xeno, удали старый скрипт из редактора.
   2. Открой файл Fust из этого архива, скопируй ВСЁ, вставь в Xeno.
   3. Execute в игре.

КАК ОБНОВИТЬ (DELTA, ТЕЛЕФОН):
   1. Залей на GitHub файлы Fust1..Fust6 из архива в КОРЕНЬ
      репозитория GalinDeonor/Test (Add file -> Upload files ->
      Commit changes). Старые Fust1..Fust6 ЗАМЕНИ новыми.
   2. В Delta вставь скрипт из файла FUST_loader_delta_037.txt
      и запусти — лоадер сам скачает 6 частей, проверит размеры
      и запустит чит.
   3. Если пишет «часть битая или не залита» — значит на GitHub ещё
      старый файл или залились не все: перезалей и проверь все 6.
