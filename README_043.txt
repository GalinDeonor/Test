ПЬЯНЫЙ ПЕТУХ 0.43 — FUST Survival
=================================

ЧТО НОВОГО (0.43 — фикс меню на телефоне):

1. ТЕЛЕФОН: МЕНЮ БОЛЬШЕ НЕ ОТКРЫВАЕТСЯ ГИГАНТСКИМ ЗА РАМКАМИ ЭКРАНА.
   Раньше оно само вставало в нормальный размер через секунду-две,
   а в этой сборке самофикс умирал. Найдены и закрыты все причины:
   - math.clamp(maxW, 280, maxW) кидал ошибку на узких экранах и весь
     блок размера молча умирал — окно оставалось 900x600;
   - телефон определялся по «нет клавиатуры», у части экзекуторов
     это врёт — теперь по TouchEnabled (85% ширины, 70% высоты);
   - размер применялся даже когда камера ещё не готова (фолбэк
     1280x800 давал окно 1088x560);
   - пересчёт вешался один раз на камеру при старте: Delta меняет
     CurrentCamera — и самофикс умирал навсегда.

2. КАК РАБОТАЕТ ТЕПЕРЬ:
   - размер применяется только при реальном вьюпорте;
   - пока вьюпорт не готов — повтор каждые 0.5с до 8 секунд (меню
     «встаёт» через секунду-две, как раньше);
   - наблюдатель перецепляется при каждой смене CurrentCamera;
   - при каждом открытии меню окно поджимается под экран.
   На ПК ничего не поменялось (до 900x600).

Всё остальное — как в 0.39 (последней стабильной): фрикам, злой аим,
ESP, чамсы лута, HUD и т.д. без изменений.

КАК ОБНОВИТЬ (XENO, ПК):
   1. Открой Xeno, удали старый скрипт из редактора.
   2. Открой файл Fust из этого архива, скопируй ВСЁ, вставь в Xeno.
   3. Execute в игре.
   Либо, если грузишь с GitHub: Fust на GitHub уже заменён на 0.43,
   просто Execute старую строку загрузки.

КАК ОБНОВИТЬ (DELTA, ТЕЛЕФОН):
   1. Залей на GitHub в КОРЕНЬ репозитория GalinDeonor/Test файлы из
      архива: Fust1, Fust2, Fust3, Fust4, Fust5, Fust6, manifest.json
      (Add file -> Upload files -> Commit, старые замени).
   2. Файл FUST_loader_delta_037.txt на GitHub УДАЛИ (он старый, ждёт
      размеры 0.37) — или оставь, но запускай лоадер 0.43 из архива:
      FUST_loader_delta_043.txt.
   3. Запусти лоадер 0.43 в Delta.
   4. Если консоль пишет «Часть N битая» — часть не долилась на GitHub,
      перезалей и запусти ещё раз.

[FUST] 1/4...4/4. Меню на телефоне открывается и через 1-2 секунды
точно стоит правильного размера (85% ширины / 70% высоты экрана).
