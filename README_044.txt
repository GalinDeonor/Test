ПЬЯНЫЙ ПЕТУХ 0.44 — FUST Survival
=================================

ЧТО НОВОГО (0.44 — радикальный фикс меню на телефоне):

1. КАК ТЕПЕРЬ УСТРОЕН РАЗМЕР МЕНЮ.
   Раньше размер окна вычислялся в ПИКСЕЛЯХ по вьюпорту в момент
   запуска — на Delta это ломалось (камера не готова, вьюпорт меняется
   после загрузки, экзекутор врёт во флагах) — и меню открывалось
   гигантским за рамками экрана.
   В 0.44 на телефоне размер и позиция меню заданы через SCALE:
   85% ширины / 70% высоты экрана, центр 50/50. Scale рендерится
   Roblox'ом правильно ВСЕГДА — никаких замеров, никаких ожиданий
   камеры. Меню физически НЕ МОЖЕТ открыться гигантским.

2. ДОПОЛНИТЕЛЬНО:
   - телефон определяется тройно: TouchEnabled, ИЛИ нет мыши+клавы,
     ИЛИ экран меньше 800x600 — что-то из этого сработает всегда;
   - при каждом открытии меню: не влезает в экран — мгновенная
     пересборка Scale;
   - перетаскивание и ресайз окна патчены под Scale-размер;
   - на ПК всё по-прежнему: окно 900x600, свободный ресайз.

3. КАК ПРОВЕРИТЬ, ЧТО ЗАПУЩЕНА НОВАЯ СБОРКА:
   в шапке меню теперь написано «FUST Survival 0.44». Нет этой
   надписи — значит запустился старый файл с GitHub.

Всё остальное — как в 0.39/0.43: фрикам, злой аим, ESP, чамсы лута,
HUD и т.д. без изменений.

КАК ОБНОВИТЬ (XENO, ПК):
   1. Открой Xeno, удали старый скрипт из редактора.
   2. Открой файл Fust из этого архива, скопируй ВСЁ, вставь в Xeno.
   3. Execute в игре.
   Либо грузишь с GitHub — замени Fust в корне репозитория на Fust из
   архива и просто Execute старую строку загрузки.

КАК ОБНОВИТЬ (DELTA, ТЕЛЕФОН):
   1. Залей на GitHub в КОРЕНЬ репозитория GalinDeonor/Test файлы из
      архива: Fust1, Fust2, Fust3, Fust4, Fust5, Fust6, manifest.json
      (Add file -> Upload files -> Commit, старые ЗАМЕНИ — это важно,
      иначе лоадер скачает старые части).
   2. Старый FUST_loader_delta_037.txt с GitHub удали.
   3. Запусти лоадер 0.44 в Delta: FUST_loader_delta_044.txt.
   4. В консоли должно появиться:
      [ПП 0.44] Часть 1..6 — по ~69900 байт
      [ПП 0.44] Всего: 419358 байт
      [FUST] 1/4 ... 4/4
   5. Открой меню: в шапке должно быть «FUST Survival 0.44», окно
      занимает 85% ширины и 70% высоты экрана сразу после открытия.

ЕСЛИ МЕНЮ ВСЁ ЕЩЁ БОЛЬШОЕ:
   - проверь, что в шапке «0.44» — если нет, на GitHub старый файл;
   - закрой и открой меню (при открытии окно пересобирается само);
   - скинь скрин меню вместе с шапкой — в лог уходит строка
     «МЕНЮ: экран ШxВ, окно ШxВ» (в консоли экзекутора).
