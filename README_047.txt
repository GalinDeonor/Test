ПЬЯНЫЙ ПЕТУХ 0.47 — ДВЕ СБОРКИ: DELTA (телефон) + XENO (ПК)

ГЛАВНОЕ
- DELTA-СБОРКА (Fust1..Fust6): фрикам ВЫРЕЗАН полностью (он и был
  причиной «не реагирует на управление / бегает на месте» — заякоривал
  тело и забирал левый джойстик). Авто-стрельба починена для телефона
  (выбор по TouchEnabled, стрельба Tool:Activate()). Всё остальное
  из обновы на месте: авто-стрельба, чамсы мебели (шкафы/локеры),
  обход анти-чита (лог киков/банов + чат), злой аим, CS2-прицел,
  админ-чек, HUD, ESP игроков/НПС, мешки/лут, хитбоксы, трассеры.
- XENO-СБОРКА (FUST_xeno_047.lua): ПОЛНАЯ — с фрикамом (K/Z/X, WASD,
  обзор ПКМ) и всеми функциями. Для ПК.

АВТО-СТРЕЛЬБА НА ТЕЛЕФОНЕ (проверка, что менять не пришлось)
- Работает через Tool:Activate() — не требует мыши и не перехватывает
  джойстик/тапы.
- Исправлена ОШИБКА ВЫБОРА ветки: раньше телефон определялся по
  KeyboardEnabled (Delta может докладывать клавиатуру -> стрельба
  молча не срабатывала). Теперь телефон = TouchEnabled.
- На ПК добавлен фолбэк: если mouse1click и VirtualInputManager
  недоступны — тоже Tool:Activate().

ЧАМСА МЕБЕЛИ / ОБХОД АНТИ-ЧИТА / CS2-ПРИЦЕЛ (телефон-проверка)
- Чамсы мебели: Highlight-инстансы — на Delta работают, ПК-only API нет.
- Обход анти-чита: только ЧТЕНИЕ баннеров/чата и лог файла — безопасно.
- CS2-прицел и HUD: Drawing — на Delta поддерживается.
- getcustomasset не используется нигде (убрали ещё в 0.39v6).
