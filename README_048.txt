ПЬЯНЫЙ ПЕТУХ 0.48 — СТАБИЛЬНАЯ БАЗА + ТОЛЬКО АВТО-СТРЕЛЬБА

ГЛАВНОЕ
- База: СТАБИЛЬНЫЙ 0.39 ДО партии правок (f19a4ba, md5 213b87db) —
  тот, на котором телефон работал.
- Из «сломанной обновы» (0.39v2-v8) взят ТОЛЬКО блок АВТО-СТРЕЛЬБЫ
  (0.39v2) с ПРОВЕРКОЙ СТЕН WallCheck (0.39v4) и телефон-фиксом 0.47
  (выбор по TouchEnabled, стрельба Tool:Activate()).
- ВЫРЕЗАНО В ОБЕИХ СБОРКАХ (Delta и Xeno одинаково):
  • ФРИКАМ — UI и движок полностью (заморозка тела, захват джойстика);
  • ESP ЛУТА — «Мешки с добычей», «Лут (бочки и ящики)», чамсы лута,
    пул Highlight-ов, скан-лупы, конфиги, вызовы;
  • чамсы мебели / обход анти-чита / правки шрифта — в стабильной базе
    их не было, поэтому их нет и тут.
- Остальное — ровно как в стабильном 0.39: ESP игроков/НПС, хитбоксы,
  аимбот + злой аим, анти-отдача/анти-тряска, трассеры, HUD, CS2-прицел,
  админ-чек, вайтлист, FullBright/NoFog/NoGrass, конфиги, кнопка-петух.
