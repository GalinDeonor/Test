ПРОЧТИ_ЗАЛИВКА_056.txt — КАК ЗАЛИТЬ 0.56 НА GITHUB (5 минут)
================================================================

ЧТО ЭТО
Это ТОЧНЫЙ набор файлов для КОРНЯ репозитория GalinDeonor/Test,
версия 0.56. Сейчас на репо стоит 0.54 (проверено 14.11), поэтому
на Xeno/Delta «нет обновления». Плюс в корне репо лежит мёртвый
файл «Fust» из 0.44 — из-за него и ощущение, что «файл ещё с 0.44».

ШАГ 1 — ЗАЛИВКА (одним коммитом)
1. Распакуй этот ZIP в любую папку.
2. Открой github.com/GalinDeonor/Test
3. Кнопка «Add file» -> «Upload files».
4. Перетащи СРАЗУ ВСЕ файлы из папки, КРОМЕ этого текстового файла
   (ПРОЧТИ_ЗАЛИВКА_056.txt на репо не заливай):
     Fust1, Fust2, Fust3, Fust4, Fust5, Fust6   (заменят старые)
     manifest.json                              (заменит старый)
     FUST_loader_delta_056.txt                  (новый)
     FUST_xeno_056.lua                          (новый)
     BUGS.md                                    (заменит старый)
     INSTRUKCIJA_056.txt                        (новый)
   GitHub сам предложит «Replace existing files» — соглашайся.
5. Внизу кнопка «Commit changes» (один коммит, не по одному файлу).

ШАГ 2 — УДАЛЕНИЕ СТАРОГО МУСОРА (чтобы не путаться)
На странице репо кликни по файлу -> иконка корзины (Delete) -> Commit.
Удалить:
     Fust                        (одиночный файл линии 0.44, НЕ НУЖЕН)
     FUST_loader_delta_050.txt   FUST_xeno_050.lua
     FUST_loader_delta_052.txt   FUST_xeno_052.lua
     FUST_loader_delta_053.txt   FUST_xeno_053.lua
     FUST_loader_delta_054.txt   FUST_xeno_054.lua
     INSTRUKCIJA_052.txt  INSTRUKCIJA_053.txt  INSTRUKCIJA_054.txt
     README_050.txt
(Для работы лоадера удаление не обязательно — старые файлы просто
валяются мёртвым грузом. Но именно файл «Fust» из 0.44 создавал
ощущение, что репо не обновляется.)

ШАГ 3 — ПРОВЕРКА ЗАЛИВКИ (обязательно!)
Открой в браузере (лучше с телефона/ПК в режиме инкогнито):
  https://raw.githubusercontent.com/GalinDeonor/Test/main/manifest.json
Должно быть:  "ver": "0.56"  и  "v": 56.
Если там 0.54 — заливка не прошла, повтори ШАГ 1.

ШАГ 4 — ЗАПУСК
XENO (ПК):  открой файл FUST_xeno_056.lua из этой папки, скопируй ВСЁ
  в Xeno (или добавь файл в Xeno) и выполни. Старый универсальный
  лоадер больше НЕ НУЖЕН — качай/запускай одиночный файл.
DELTA (телефон):  вкладка со старым лоадером -> стереть -> вставить
  текст FUST_loader_delta_056.txt -> EXECUTE. В консоли должно быть
  «[ПП 0.56] Лоадер запущен... Часть 1..6 ... байт».
